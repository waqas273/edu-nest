1Free Leaflet Map Integration Architecture

EduNest implements an open-source, coordinate-based mapping layer utilizing Leaflet.js and the OpenStreetMap (Nominatim) API. This replaces commercial alternatives (such as Mapbox or Google Maps APIs) to eliminate mandatory credit card requirements and usage fees.

LeafletLocationPicker

Used inside the University Manager dashboard. Enables managers to input their university address with search-as-you-type forward geocoding, drop pins manually, and automatically reverse-geocode to find coordinates and city details.

LeafletCampusView

Embedded in the Student Details view. Renders the campus location using highly styled popups, custom map controls, and action shortcuts to launch external directions services.

A. Key Engineering Features

  • Dynamic Theme Toggling: The map listens to changes on the root document element via a MutationObserver. It switches visual tile layers dynamically: CartoDB Dark Matter slate tiles in dark mode, and CartoDB Voyager tiles in light mode.
  • Pulsing Custom SVG Markers: Uses inline SVG designs wrapped inside Leaflet's L.divIcon. This prevents asset resolution failures commonly caused by Webpack/Vite image bundles.
  • Zero-Key Geocoding: Leverages Nominatim endpoints to fetch geocoding data. Limits searches to Pakistan using the countrycodes=pk parameter for faster results.
  • Iframe Fallback Support: If a university profile does not have coordinates configured, the system falls back gracefully to a Google Maps search iframe, ensuring the page never crashes.

2Dynamic Hybrid Recommendation Engine

To match student interests with matching campuses, the system scores and filters Universities and Programs using a multi-factor formula.

Overall Recommendation Score Formula
Score(100 Pts) = (Academic Interest Match × 50%) + (Geographical Proximity × 30%) + (Review Ratings Strength × 20%)
Minimum score threshold to be displayed in "Recommended for You" feed: 50 Points

A. Academic Interest Match (Max 50 Points)

The student's career interest (determined by the AI assessment) is matched against degrees using a semantic vocabulary:

  • Scoring Scale (Universities): 50 Points for 3+ matching degrees, 45 Points for 2 matches, 40 Points for 1 match, and 0 Points for no matches.
  • Scoring Scale (Individual Programs): 50 Points if the title contains keywords; otherwise 0 Points.

B. Hybrid Location Proximity (Max 30 Points)

To support students who prefer close campuses, the engine uses real-time browser GPS tracking with text fallbacks:

The Haversine Distance Formula
d = 2R · arcsin ( √ sin2(Δlat / 2) + cos(lat1)·cos(lat2)·sin2(Δlng / 2) )
Where R is Earth's radius (6,371 km), and d is calculated physical distance in Kilometers
  • Active GPS Mode: Uses navigator.geolocation to get the browser coordinates.
    • Distance ≤ 15 Kilometers: 30 Points (Immediate local area)
    • Distance ≤ 50 Kilometers: 20 Points (Close proximity)
    • Distance ≤ 150 Kilometers: 15 Points (Moderate distance)
    • Distance > 150 Kilometers: 10 Points (Far distance)
  • Text Fallback Mode: If GPS is disabled or blocked, the system compares the student's home city name with the campus city name. If they match, the system awards 30 Points; otherwise, it defaults to 10 Points.

C. Review Ratings Strength (Max 20 Points)

Calculates academic authority based on verified ratings:

  • Equation: Round( (Average Rating / 5.0) * 20 )
  • Scale Examples: 5.0 Stars yields 20 Points; 4.0 Stars yields 16 Points; 3.0 Stars yields 12 Points.
  • Neutral Fallback: If a university has no reviews yet, it defaults to 3.5 Stars (yielding 14 Points) to remain fair and unbiased.
