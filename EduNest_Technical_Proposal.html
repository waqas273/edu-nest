1Introduction and Objectives

This proposal describes the implementation of a Retrieval-Augmented Generation (RAG) system for the entry test preparation module of EduNest. Instead of relying on the general pre-trained memory of Large Language Models, which often introduces factual errors or out-of-syllabus terms, this system retrieves specific textbook paragraphs related to the student's selected topic and feeds them directly to the AI model. This approach guarantees that all generated questions strictly adhere to the official FSc Intermediate curriculum guidelines.

The primary objectives of this implementation include:

  • 1 Curriculum Accuracy: All generated test questions are grounded in text retrieved from official provincial textbook publishers.
  • 2 Hallucination Elimination: By referencing verified physical pages, the LLM is restricted from generating incorrect factual information or formulas.
  • 3 API Key Security: All external API credentials and client calls are handled on the Python backend, keeping keys secure and hidden.

2Academic Data Sources

Our reference database is built by compiling official textbook PDFs from state-authorized education departments. This ensures complete coverage across different provincial boards:

📘

4Implementation Methodology

The implementation processed raw FSc textbooks into a searchable semantic database through a four-stage ingestion pipeline:

  • 📄 Text Extraction: We read the official textbook PDFs page-by-page using the Python pypdf library, extracting raw text and cleaning unreadable symbols.
  • ✂️ Dynamic Chunking: The extracted text is split into small paragraphs (500–1,000 characters) with a 100-character overlap to ensure concepts are not severed at boundaries.
  • 🧠 Vector Embeddings: We convert text chunks into numerical vectors representing semantic meaning, utilizing the local, CPU-based all-MiniLM-L6-v2 model.
  • 🗄️ Vector Storage: The vectors are stored in a local ChromaDB database tagged with Subject and Chapter metadata parameters for fast, structured retrieval queries.

6Security, Reliability & Cost Feasibility

🔒
Credential Security
API credentials are stored as Flask environment variables on the backend, hidden from the browser client.
💰
Zero Search Cost
Local models (`sentence-transformers` and `ChromaDB`) ensure vectorization and search queries are completely free.
🛡️
System Reliability
A local database file acts as a backup offline fallback to maintain operations during network failures.
