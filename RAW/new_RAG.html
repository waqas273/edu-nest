What is this guide?

This technical report explains how our upgraded entry test module reads old papers, maps the **exact sequence of topics** (which topic appears at which question number), searches FSc textbooks for those specific chapters, and has AI write a test matching that exact chronological structure.

1The Big Picture of Alignment

In a real MDCAT or ECAT exam, questions do not appear in random order. They follow a strict, structured layout. For example, in a real 100-question ECAT paper:

  • Questions 1 to 10: Always cover Mathematics (Algebra & Calculus).
  • Questions 11 to 20: Always cover Physics (Mechanics & Motion).
  • Questions 21 to 30: Always cover Chemistry (Atomic Bonding & Gases).

We want our AI-generated tests to match this **exact structural sequence** so the student feels like they are attempting a real exam. The process is split into three simple steps:

Chronological Generation Cycle
Step 1: Scan Pattern
Map which chapter is at which question index
→
Step 2: Search Book
Find textbook chapters in that exact sequence
→
Step 3: AI Generation
Write questions matching the index template

A Concrete Example of Structural Matching:

If past papers always put a question about "Centripetal Force" at **Question #1**, the system will query the *Circular Motion* chapter in the FSc textbook database to generate the content for **Question #1**. If **Question #2** is historically about "Gaseous State", the system will query the *Chemistry Gas Laws* chapter to generate **Question #2**.

2Step 1: Scanning Exam Patterns

We have old MDCAT and ECAT solved PDFs in python_backend/data/past_papers/. We run an offline Python script (analyze_past_papers.py) once to analyze their chronological layout.

1
Parse Question Sequences
The script loops through the past papers question-by-question (Q1, Q2, Q3) to analyze what subject, chapter, and topic is covered at each specific index.
2
Map Question Indexes
It maps each index. For example: Q1 = Physics/Circular Motion, Q2 = Physics/Electrostatics.
3
Store Solved Templates
For each question index, it saves the actual solved question as a style template. This teaches the AI the exact style of that index.
4
Export Map
It saves the sequence map in syllabus_weightage_map.json. This acts as the structural template.

Example of the Pattern JSON Structure:

{
  "mdcat": {
    "Physics": {
      "sequence_map": [
        {
          "q_num": 1,
          "chapter": "Circular Motion",
          "difficulty": "Moderate",
          "style_reference": {
            "q": "When a body moves in a circle, its velocity is...",
            "ans": "Tangent to path"
          }
        },
        {
          "q_num": 2,
          "chapter": "Electrostatics",
          "difficulty": "Hard",
          "style_reference": {
            "q": "Determine the electric force between...",
            "ans": "10 Newtons"
          }
        }
      ]
    }
  }
}

3Step 2: Sequence-Guided Textbook Search

When a student starts a new test, the backend server loads the sequence_map from our JSON file. It processes the questions **chronologically** to build the test paper.

How the Sequential Retrieval works:

The server loops from Question 1 to Question N:

  • For Question #1: The map says this index needs "Circular Motion". The backend queries ChromaDB for FSc textbook text matching "Circular Motion basics centripetal velocity".
  • For Question #2: The map says this index needs "Electrostatics". The backend queries ChromaDB for textbook text matching "Coulomb's Law electric field equations".

Instead of pulling random textbook blocks, this sequence-guided query ensures that the textbook context passed to the generator matches the exact chronological order of the real board syllabus exam.

4Step 3: AI Prompt & Layout Grounding

Now, the backend sends the generated textbook context and the style template to the AI model (Groq Llama 3.3).

Prompt Design for Question Index #1:

You are an expert board examiner. Please write Question #1 for our test.

TEXTBOOK CONTEXT (Only use these facts):
"In a circular path, centripetal velocity is always tangential. The direction of acceleration is towards the center."

STYLE REFERENCE (Write a new question matching this pattern):
Original Question: When a body moves in a circle, its velocity is...
Original Answer: Tangent to the path

INSTRUCTIONS:
1. Write a new question about direction or velocity in a circle.
2. Match the exact difficulty level: "Moderate".
3. Return the question as a JSON object.

Output for Question Index #1:

{
  "id": 1,
  "subject": "Physics",
  "difficulty": "Moderate",
  "question": "What is the direction of the velocity of a particle in circular motion?",
  "options": ["A) Towards center", "B) Tangent to circle", "C) Away from center", "D) Parallel to axis"],
  "answer": "B) Tangent to circle",
  "explanation": "tangential velocity direction is always tangent to the circle path."
}

5Offline Backups & Cheating Security

To build a professional app, we ensure it never crashes during exams and students cannot cheat.

1
Offline Backup Database
If the Groq API fails or is rate-limited, the backend does not crash. It loads the original solved questions from past_papers_extracted.json corresponding to the exact same question index numbers. The student's session remains stable.
2
Window Switch Cheating Lock
The React application (MockExam.jsx) monitors browser tabs. If a student leaves the screen to search an answer:
  • 1st & 2nd tab switch: A warning overlay locks the screen.
  • 3rd tab switch: The exam is auto-submitted, and saved as "Aborted" in Firestore with the reason "Tab Switch Limit Exceeded".
3
Official Grading Schemes
Timing and score calculation rules match board blueprints:
  • MDCAT (Medical): 180 questions, 180 minutes, no negative marking (+1 for correct).
  • ECAT (Engineering): 100 questions, 100 minutes, with negative marking (+4 for correct, -1 for wrong).
Summary of benefits

This upgraded hybrid RAG layout guarantees that every generated test matches the exact structure, chapter order, difficulty distribution, and style of real historical board exams.
